# LNK Forensic Analysis Platform

Advanced browser-based forensic tool for analyzing Windows LNK files.

## Features
- LNK parsing & analysis dashboard
- Rule-based detection engine (16 rules)
- IOC extraction (IP, domain, URL, UNC, PowerShell)
- Diff comparison between datasets
- Interactive UI for threat hunting

## Usage
1. Export LNK data using provided PowerShell script
2. Upload JSON file into the platform
3. Analyze results in browser
